# Agribusiness Data Analysis Internship

This repository contains my work for the agribusiness data analysis internship.

## Week 1: Agribusiness Data Analysis Planning

The Week 1 task focuses on developing a structured plan for collecting and analyzing publicly available agribusiness data.

The report covers:

- Research rationale
- Potential public agricultural data sources
- Key agricultural metrics
- Data collection process
- Data cleaning process
- Data analysis and interpretation
- Five-week project timeline
- Expected outcomes

## Potential Data Sources

- Open Government Data Platform India
- Directorate of Economics and Statistics
- Agriculture Census
- Food and Agriculture Organization (FAO)
- World Bank Open Data
