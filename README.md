## Week 2: Data Cleaning and Preprocessing Strategy

The Week 2 task focused on assessing and preparing the FAOSTAT Producer Prices dataset for India.

### Dataset Overview

- **Source:** FAOSTAT
- **Dataset:** Producer Prices
- **Records:** 5,035
- **Columns:** 16
- **Coverage:** Agricultural producer prices and price indices across commodities and years

### Work Completed

- Examined the dataset structure and data types.
- Identified and assessed missing values.
- Checked for duplicate records and inconsistencies.
- Standardised column names and removed unnecessary whitespace.
- Converted relevant columns to appropriate numeric data types.
- Validated measurement units and numeric values.
- Examined wheat producer price records and distinguished actual prices from price index values.
- Prepared a cleaned dataset for further analysis.

### Key Findings

- The dataset contained 5,035 records and 16 columns.
- A total of 3,640 missing values were identified in the `Unit` column, mainly for the Producer Price Index, where a measurement unit is not applicable.
- No exact duplicate records were found.
- The cleaning process preserved the original dataset dimensions and retained meaningful missing values.
